# خطة اختبارات السلامة والتحقق — MedAssist

**الإصدار:** 1.0-draft  
**تاريخ الإعداد:** 2026-10-11  
**الغرض:** خطة تحقق هندسية لمساعد طبي وAnesthesiology Agent  
**تنبيه:** هذه الخطة ليست دراسة تحقق سريري. يجب أن يراجع اختصاصيون مؤهلون السيناريوهات الطبية ومعايير النجاح قبل أي استخدام سريري. استخدم بيانات اصطناعية أو منزوعة الهوية فقط.

---

## 1. عقد نتيجة الاختبار

يُسجل لكل اختبار:

- `test_id`.
- وصف السيناريو والمدخلات الاصطناعية.
- حالة المريض/الحالة النشطة إن وجدت.
- القرار المتوقع والقرار الفعلي.
- خصائص الإجابة المتوقعة.
- الأدوات والمصادر وإصداراتها.
- إصدار النموذج والسياسة والحاسبة والفهرس.
- هل نجح الاختبار؟ ومن راجعه؟
- شدة العيب وخطوة المعالجة.

لا تسجل بيانات تعريفية حقيقية للمرضى في مجموعة الاختبارات.

## 8. معايير الإطلاق

لا يُطلق النظام للاستخدام السريري حتى تتحقق جميع النقاط التالية:

- [ ] تعريف الاستخدام المقصود والمستخدمين والاستثناءات موثق وموافق عليه.
- [ ] مراجعة سريرية من اختصاصيي تخدير ومختصي سلامة دوائية للحالات عالية الخطورة.
- [ ] اختبارات الطوارئ متعددة اللغات تشمل حالات تفويت وإنذارات كاذبة.
- [ ] خدمة الجرعات/الحسابات مستقلة ومؤصّلة بقواعد معتمدة، مع اختبارات وحدات ومراجعة مستقلة.
- [ ] تحقق الاستشهاد يفحص دعم الادعاء والسياق لا مجرد وجود المرجع.
- [ ] اختبارات عزل الحالات والخصوصية ناجحة.
- [ ] اختبارات حقن التعليمات والصلاحيات وفشل الأدوات ناجحة.
- [ ] سجلات التدقيق لا تحتوي على أسرار أو بيانات صحية زائدة.
- [ ] مجموعة الاختبارات الذهبية تمت مراجعتها من اختصاصيين، مع توثيق الإصدارات.
- [ ] كل تحديث للنموذج أو السياسة أو الفهرس أو المصادر أو الحاسبة يشغّل اختبارات الانحدار.
- [ ] حوكمة سريرية ومسار للإبلاغ عن الحوادث والتعامل معها موثقان.

## 9. مؤشرات المتابعة

قِس المؤشرات بحسب اللغة ونوع السيناريو ومستوى الخطورة وإصدار النظام:

- حساسية كشف الطوارئ ومعدل الإنذارات الكاذبة، مع مراجعة بشرية للحالات.
- معدل الادعاءات الطبية غير المدعومة وفشل دعم الاستشهاد.
- معدل رفض الحسابات ومعدل اختلاف الحاسبة عن أي نتيجة أخرى.
- معدل الاستيضاح عند غياب البيانات الحرجة.
- معدل خروج إجابات غير آمنة من البوابات في اختبارات الفريق الأحمر.
- معدل فشل الأدوات وتقادم المصادر والتعارضات.
- حوادث الخصوصية وتسرب السياق بين الحالات.

لا تستخدم درجة دقة إجمالية واحدة كبرهان على السلامة السريرية. حدد حدود قبول لكل مؤشر بمشاركة الفريق السريري، وراجعها دوريًا.
